to write.

This editor saves a draft in this browser only. It does not publish directly. Download your updated journal file, then replace posts.json on GitHub to publish through your authorised GitHub account.

Upload the downloaded posts.json to GitHub →

On GitHub, select the downloaded file, keep its name as posts.json, and commit the change to main. It replaces the existing journal file. GitHub Pages will rebuild. Keep a copy of your writing; browser storage is not a backup. This editor is public, but only someone with repository write access can publish.
